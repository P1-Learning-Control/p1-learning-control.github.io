Using Outlook, Apple Calendar, or another calendar?

You can subscribe to the event calendar using the public calendar address below. A subscription will allow your calendar application to receive future event updates.

https://calendar.google.com/calendar/ical/0a6e25047262cd8edb06c084caaaac34a52024b297de86f546c29ce3aeaaaa77%40group.calendar.google.com/public/basic.ics

Outlook

  1. Open Outlook Calendar.
  2. Select Add calendar.
  3. Select Subscribe from web.
  4. Paste the calendar address above.
  5. Select Import or Add.

Apple Calendar

  1. Open the Calendar app.
  2. Select File → New Calendar Subscription.
  3. Paste the calendar address above.
  4. Select Subscribe.

Other calendar applications

Look for an option such as Subscribe to calendar, Add calendar from URL, or Subscribe from web, and paste the address above.
